# أثر ميديا — Athar Media

موقع شركة **أثر ميديا** للتسويق الرقمي (تصميم المواقع والإعلانات للمطاعم والعيادات والمتاجر والكافيهات في غزة).
موقع ثنائي اللغة (عربي / إنجليزي) مبني على **Django + HTML + CSS + JavaScript**.

شعار الشركة: *نصنع أثراً رقمياً يَدوم — Creating Digital Impact*

---

## 🚀 التشغيل (Run locally)

```powershell
# 1) تفعيل البيئة الافتراضية
.\venv\Scripts\Activate.ps1        # أو استخدم .\venv\Scripts\python.exe مباشرة

# 2) تشغيل الخادم
python manage.py runserver
```

ثم افتح المتصفح على: **http://127.0.0.1:8000/**

> إذا ظهرت مشكلة ترميز في الطرفية، شغّل أولاً: `$env:PYTHONUTF8="1"`

---

## 🔑 لوحة التحكم (Admin)

| | |
|---|---|
| الرابط | http://127.0.0.1:8000/admin/ |
| اسم المستخدم | `admin` |
| كلمة المرور | `Athar@2026` |

> **مهم:** غيّر كلمة المرور قبل النشر: `python manage.py changepassword admin`

من لوحة التحكم يمكنك إدارة:
- **الخدمات** — إضافة/تعديل الخدمات وأيقوناتها (عربي + إنجليزي).
- **الأعمال** — رفع صور المشاريع وتصنيفها (مطاعم/عيادات/متاجر/كافيهات).
- **آراء العملاء** — التوصيات والتقييمات.
- **رسائل التواصل** — الرسائل الواردة من نموذج "تواصل معنا".
- **إعدادات الموقع** — الهاتف، الواتساب، البريد، العنوان، روابط التواصل الاجتماعي، والخريطة.

---

## ⚙️ تعديل معلومات التواصل والواتساب

افتح **لوحة التحكم → إعدادات الموقع** وعدّل:
- **الهاتف / البريد / العنوان / ساعات العمل**
- **واتساب**: ضع الرقم بالصيغة الدولية بدون رمز `+` (مثال: `970590000000`) — سيظهر زر واتساب عائم وروابط مباشرة.
- **روابط التواصل**: فيسبوك، إنستغرام، تيك توك، لينكدإن... (تظهر تلقائياً في الهيدر والفوتر وصفحة التواصل).
- **الخريطة**: ضع رابط `src` من خريطة جوجل (Embed) ليظهر موقعك في صفحة التواصل.

---

## 🌐 نظام اللغتين

- اللغة الافتراضية **العربية** (RTL)، مع زر تبديل إلى **English** (LTR) في الهيدر.
- نصوص الواجهة في `core/i18n.py` (عربي + إنجليزي) — سهلة التعديل.
- محتوى قاعدة البيانات لكل عنصر له حقلان: `_ar` و `_en`.

│   ├── forms.py         نموذج التواصل

├── templates/           قوالب HTML (base + partials + pages)
├── static/

## 📦 ملاحظات النشر (Production)

قبل رفع الموقع على استضافة حقيقية:
1. في `athar_media/settings.py`: اجعل `DEBUG = False`، وحدّث `ALLOWED_HOSTS`، وغيّر `SECRET_KEY`.
2. شغّل `python manage.py collectstatic`.
3. استخدم خادم WSGI (مثل Gunicorn/uWSGI) خلف Nginx، وقاعدة بيانات PostgreSQL للإنتاج.
